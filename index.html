Saving and continuing later

This page does not save automatically. If you close or refresh the tab, your work is gone unless you saved it as a file first.

That file ends in .json. Think of it as a save game: it holds your teams, logos, fixtures, scores and settings. You do not open it in Word or edit it yourself. Only this app reads it.

  1. 1Save: click Save at the top. A file downloads to your Downloads folder.
  2. 2Keep it safe: leave it where it is, or copy it to Google Drive, email or WhatsApp yourself.
  3. 3Continue later: open this page again, click Open and choose that file. Everything comes back as you left it.
Tip: save again after you change teams or fixtures. Each save makes a new file with today's date, so older ones stay as backups.
